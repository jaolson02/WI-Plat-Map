# Driftless Plat Map

A phone-friendly map of Wisconsin property lines, owners and public land, built only on free official data.

- Property lines and owner info: Wisconsin Statewide Parcel Map (V12), State Cartographer's Office and the Wisconsin Land Information Program.
- Public land: Wisconsin DNR managed lands and the DNR public land service (county forest, federal, BCPL).
- Imagery and topo: USGS National Map.

Lines are approximate and are not a survey. Confirm ownership with the county.
